Portfolio allocation with transaction costs



Marcelo Fernandes (FGV-EESP), joint work with Gustavo Grivol (NYU Stern), Duda Mendes (FGV-EESP)



Abstract: We tackle the portfolio optimization problem with transaction costs using regularization methods. In contrast to the extant approaches, we do not impose an arbitrary turnover penalization. We instead show that properly accounting for transaction costs induces regularization, with a set of penalty functions based on different norms. In particular, the functional forms of the penalty functions depend on the transaction cost model we employ. We implement our portfolio optimization approach for both simulated and real data, with very promising results.
